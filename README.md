# Squarehaven 1.0 TEST
Native Java/Canvas Android 8+ Tasquare touching-square-area puzzle.

Shade blank cells so every edge-connected dark group is a filled square. All light cells, including clues, stay edge-connected. Each fixed light clue is the sum of the full areas of all dark squares sharing a side with that clue. Count each touching square once, not its touching edges or neighboring cells. Twelve unique 4x4 clue boards have twelve distinct solutions, each with a 2x2 square.

Saved square palette and shade marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java set-components and Cartesian-product square oracle checks all 65536 shading masks per board against production bounding-box squares and bitset connectivity, proving one solution each. Fixed clues, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 101 recovered READMEs and recent cumulative stages/releases found no Tasquare match. Shared Blockbloom component-shape shading is disclosed, but square components and per-clue whole-component area sums plus light connectivity replace arbitrary rectangles and outlined-room shade quotas. Unlike Rangefern exact-distance landings, clues refer to whole touching square areas; unlike Nearwillow local neighbor totals, a 2x2 square contributes four even when only one cell touches. Known Tasquare genre, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed. Rules https://ericfox53.blogspot.com/2022/01/424-tasquare.html .
